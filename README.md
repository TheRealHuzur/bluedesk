# BlueDESK

BlueDESK is a powerful and intuitive **Service Blueprint Tool** designed to help teams visualize, design, and optimize service processes. It provides a structured, grid-based interface for mapping out customer actions, frontstage/backstage interactions, and support processes across different phases of a service journey.

![BlueDESK Preview](https://via.placeholder.com/800x400.png?text=BlueDESK+Service+Blueprint+Tool)

## ✨ Features

-   **Interactive Blueprint Grid**: Easily manage phases and lanes to map out complex service architectures.
-   **Dynamic Phase Management**: Add, rename, reorder, or delete phases. Each phase can have statuses like *Planung*, *ToDo*, *In Progress*, or *Done*.
-   **Flexible Lane System**: Customize your blueprint with lanes for Physical Evidence, Customer Actions, Frontstage, Backstage, Support Processes, Pain Points, and Chancen (Opportunities).
-   **Card-Based Documentation**: Add detailed notes or actions (cards) within each phase-lane intersection.
-   **JSON Export/Import**: Save your progress or collaborate by exporting your entire blueprint to a JSON file and loading it back later.
-   **Premium Dark Design**: A modern, sleek interface with glassmorphism effects, vibrant accents, and smooth animations.
-   **GDPR Compliant**: Built with German data protection standards in mind, utilizing local font hosting and no external tracking.

## 🚀 Tech Stack

-   **Frontend**: Vanilla HTML5, CSS3 (Custom Design System), and pure JavaScript (No frameworks).
-   **Typography**: Inter (System-ui fallback).
-   **Icons**: Material Design SVG Icons (Integrated Sprite).
-   **Persistence**: Client-side JSON handling (No database required).

## 🛠️ Getting Started

BlueDESK is a **single-file application**. To run it:

1.  Download or clone this repository.
2.  Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
3.  Start building your blueprint immediately!

## 📖 Usage

-   **Adding Content**: Click on the placeholders within the grid to add new phases, lanes, or cards.
-   **Managing Items**: Use the icons that appear on hover to edit or delete cards, phases, and lanes.
-   **Data Management**: Use the "JSON Export" button in the header to save your work. You can reload it later using the "JSON Laden" button.
